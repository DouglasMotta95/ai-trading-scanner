Build local/descompactada continua em modo de desenvolvimento. Em produção, o scanner exige uma licença ativa quando esta opção estiver habilitada.

Quando o backend estiver rodando, abra http://localhost:8787/admin para gerar licenças, ver clientes online, planos e consumo diário. A chave usada lá é ATS_ADMIN_KEY, definida no backend.
